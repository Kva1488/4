# Как открыть игру для всех и включить покупки за робуксы

Опубликовать игру и создать геймпассы можно только из твоего аккаунта Roblox. Код уже готов: осталось опубликовать место, сделать его публичным и вписать номера (ID) товаров в **один файл**: `src/shared/Monetization.luau`, таблица `IDS` в начале.

Пока ID = 0, в Studio кнопки «купить» выдают товар **бесплатно** (чтобы проверить, как всё работает), а в опубликованной игре такие товары помечены «Скоро в продаже».

## 1. Опубликовать место

1. Открой `Game.rbxl` в Roblox Studio (или подключи Rojo: `rojo serve`, плагин Rojo → Connect).
2. **File → Publish to Roblox** → «Create new experience». Придумай название (например, «Перчатка Бесконечности: Битва героев»), описание и жанр.
3. **Home → Game Settings → Security** → включи **Enable Studio Access to API Services**, чтобы в Studio работали сохранения (DataStore).
4. Сохрани настройки и ещё раз сделай **File → Publish to Roblox**.

## 2. Сделать игру публичной

1. Открой [create.roblox.com](https://create.roblox.com) → **Creations** → своя игра.
2. Заполни **анкету о содержимом (Maturity / Experience Questionnaire)**: без неё Roblox не даст открыть игру всем.
3. В настройках игры поставь доступ **Public** и сохрани.
4. Добавь иконку и 2–3 скриншота: так игру чаще открывают.

## 3. Создать геймпассы (покупаются один раз)

На create.roblox.com → твоя игра → **Monetization → Passes → Create a Pass**: картинка, название, описание → Create. Затем открой пасс → **Sales** → включи продажу, поставь цену → Save. Номер пасса (ID) — в адресе страницы или в меню «⋯ → Copy Asset ID».

| Ключ в `IDS` | Название | Цена (R$) | Что даёт |
|---|---|---|---|
| `StonePower` | Камень Силы | 49 | Камень сразу в Перчатку |
| `StoneSpace` | Камень Пространства | 49 | — |
| `StoneReality` | Камень Реальности | 49 | — |
| `StoneSoul` | Камень Души | 49 | — |
| `StoneTime` | Камень Времени | 49 | — |
| `StoneMind` | Камень Разума | 49 | — |
| `StarterPack` | Стартовый набор | 99 | 2 случайных камня из тех, что ещё нет, + 2500 монет (один раз) |
| `DoubleCoins` | x2 монет | 149 | Вдвое больше монет навсегда |
| `DoubleXp` | x2 опыта | 149 | Вдвое больше опыта навсегда |
| `HeroGodLoki` | Локи, бог времени | 149 | Открыть героя сразу |
| `HeroInfinityUltron` | Альтрон бесконечности | 199 | — |

## 4. Создать Developer Products (можно покупать много раз)

Там же → **Monetization → Developer Products → Create**: название, цена → Save. Скопируй ID.

| Ключ в `IDS` | Название | Цена (R$) |
|---|---|---|
| `Coins1000` | 1 000 монет | 25 |
| `Coins5000` | 5 000 монет | 99 |
| `Coins20000` | 20 000 монет | 299 |
| `Xp1000` | 1 000 опыта | 25 |
| `Xp5000` | 5 000 опыта | 99 |

## 5. Вписать ID и опубликовать

1. Открой `src/shared/Monetization.luau` и замени нули в таблице `IDS` на свои номера. Можешь прислать мне список «ключ = номер», и я вставлю сам.
2. Если цену на сайте поставил другую, поправь её и в `price` (это только витрина в игре).
3. Пересобери (`rojo build -o Game.rbxl`) или синхронизируй Rojo и снова **File → Publish to Roblox**.

После этого покупки работают по-настоящему: геймпассы проверяются при входе и сразу после покупки, а каждая покупка монет или опыта выдаётся ровно один раз, даже если сервер перезапустится.

> В Studio покупки с настоящими ID показывают тестовое окно Roblox: робуксы не списываются.
